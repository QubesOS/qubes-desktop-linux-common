=========
qvm-xget-focus
=========

NAME
====
qvm-xget-focus - print out the name of the currently focused qube

SYNOPSIS
========
| qvm-xget-focus

DESCRIPTION
===========
qvm-xget-focus prints out the currently focused qube, unless it is dom0 which doesn't return anything.

qvm-xget-focus can be useful for other scripts to perform some action on the current qube
