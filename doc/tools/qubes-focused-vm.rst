qubes-focused-vm

NAME
====
qubes-focused-vm - print out the name of the currently focused qube

SYNOPSIS
========
| qubes-focused-vm

DESCRIPTION
===========
qubes-focused-vm prints out the currently focused VM.

qubes-focused-vm can be useful for other scripts to perform some action on the current VM
